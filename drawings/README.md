# Drawings

Put architectural drawing files here (PDF, JPG, whatever format they come
in), then link to them from [pages/plans.html](../pages/plans.html):

```html
<li><a href="../drawings/your-file.pdf">Your Drawing Name</a></li>
```

This file exists just so the empty folder is tracked in git — delete it
once there are real drawings in here, or leave it, it won't affect the site.
